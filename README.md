# Vante — Dashboard de Estudos

Dashboard pessoal para acompanhamento de estudos de **Tráfego Pago** e **Design Gráfico**, com progresso salvo localmente.

## Funcionalidades

- 🔐 Tela de login com senha de acesso
- 📚 Dois cursos: Tráfego Pago (74 aulas) e Design Gráfico (57 aulas)
- 🎬 Cards com thumbnail do YouTube + link direto para assistir
- ✅ Marcação de aulas assistidas com progresso salvo no navegador
- 📊 Barras de progresso global e por módulo
- 🌙 Interface dark mode com sidebar responsiva

## Tecnologias

- HTML5 + CSS3 + JavaScript (vanilla)
- `localStorage` para persistência de progresso
- YouTube Thumbnail API para miniaturas

## Estrutura

```
CursoPessoal/
├── index.html   → Estrutura principal (login + app)
├── style.css    → Estilos (dark theme, componentes)
└── app.js       → Dados dos cursos + toda a lógica
```

## Como usar

Basta abrir o `index.html` no navegador ou acessar o link do Vercel.

**Senha padrão:** `Vante2026`
